# PI-Web

Estrutura inicial de um site estatico usando HTML, CSS e JavaScript puro.

## Estrutura

- `index.html`: estrutura e conteudo principal da pagina.
- `css/style.css`: estilos, cores, tipografia e responsividade.
- `js/script.js`: interacoes e comportamentos da pagina.
- `assets/images/`: imagens do projeto.

## Como iniciar

Abra o arquivo `index.html` no navegador. Para uma experiencia melhor durante o desenvolvimento, use a extensao Live Server do VS Code.

## Proximos passos

1. Troque o titulo, textos e links em `index.html`.
2. Ajuste as variaveis de cor no inicio de `css/style.css`.
3. Adicione imagens em `assets/images/` e referencie-as no HTML.
4. Coloque interacoes especificas do projeto em `js/script.js`.
